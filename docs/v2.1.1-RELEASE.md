# CalOohPay v2.1.1 Release Documentation

## 📦 Release Information

- **Version**: 2.1.1
- **Release Date**: October 10, 2026
- **Type**: Patch Release (dependency update, no API or behaviour changes)
- **Compatibility**: Same as v2.1.0 (browser via `caloohpay/core`, Node.js via `caloohpay` and `caloohpay/node`)
- **Test Coverage**: 359 tests passing

## 🎯 Overview

Version 2.1.1 is a maintenance release. Calculation logic, exports and CLI output are identical to v2.1.0. The change that reaches users is an updated runtime dependency, plus a one-line CLI change that keeps the new version of that dependency from adding output.

## 🔄 What Changed

### Runtime dependency

| Package | v2.1.0 | v2.1.1 |
| ------- | ------ | ------ |
| `dotenv` | `^16.4.5` | `^18.0.6` |

`dotenv` loads the `.env` file that holds your `API_TOKEN`. `dotenv` 18 supports Node.js 12 and newer.

`dotenv` 17 and later print an `◇ injected env (N) from .env` line to stderr every time `config()` runs. The CLI now calls `dotenv.config({ quiet: true })`, so you will not see that line and output is the same as v2.1.0. `.env` loading itself is unchanged.

### Package contents

AI-agent tooling files (`.claude/`, `AGENTS.md`, `CLAUDE.md`, `.env.example`) are excluded from the published package.

### Security

- `npm audit --omit=dev` reports no vulnerabilities for production dependencies.
- Development-only dependencies were updated to clear advisories. They are not installed by consumers of the package.

## 📥 Installation

```bash
npm install caloohpay@2.1.1
# or globally for the CLI
npm install -g caloohpay@2.1.1
```

## ⬆️ Upgrading from v2.1.0

No code changes are needed. Update the package and run your usual command, for example:

```bash
caloohpay -r "SCHEDULE_ID"
```

If you load your own `.env` with `dotenv` in the same project, review the [dotenv changelog](https://github.com/motdotla/dotenv/blob/master/CHANGELOG.md) for versions 17 and 18, since your own dependency is separate from the one CalOohPay uses.
